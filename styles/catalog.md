# 风格选型目录（15 种内置 MG 风格）

选型三步：**按内容/目的圈定 2–3 个候选 → 按情绪气质与制作成本收敛 → 按画幅/平台确认**。
选不出时给用户 1 个主推 + 最多 2 个备选（各一句话理由）。

## 二、按情绪气质

- 温暖手作、呼吸感、反数字精致 → 05
- 冷静、理性、严肃、可信 → 19、09、02
- 高级、慢、贵、透 → 12、02、04
- 高能量、弹跳、快乐、热闹 → 01、18、07
- 复古怀旧（80s / 千禧 / 8-bit / 老杂志） → 10、20、06
- 硬核、酷炫、赛博 → 22、10

## 三、按画幅 / 平台

- **横屏 16:9**：全部风格默认 1920×1080。
- **竖屏 9:16**：18 综艺花字原生 1080×1920；其余风格把 Output 改为 1080×1920，并确保构图描述适配竖屏。
- 平台倾向：B站 / YouTube → 横屏优先；抖音 / 快手 / Reels / Shorts → 竖屏（18 最契合）。

## 四、按制作成本

- **轻（纯 Web 2D）**：01、02、08、09、19、18、22、05（Canvas 笔刷）、20（低清 Canvas）、03（SVG 路线）
- **中（WebGL shader）**：07、10、12；03 的 Three.js 路线
- **重（Blender 离线渲染）**：04 —— 需要 Blender，渲染耗时长；需求只求"质感高级"但环境无 Blender 时，向用户说明后可改推 12 或 07。

## 五、15 种风格一览

> 模板文件在 `styles/templates/<编号>.md`，内含该风格的 5 个专属段落原文。
> "seed 基因" = 定制 Creative seed 时必须保留的风格根性（写进新 seed 的结构要素）。

### 01-flat-vector · 扁平矢量动画 Flat/Vector 2D Motion Graphics
- 定位：MG 基本盘，源自 explainer 传统；纯色几何大色块，一切皆矢量形状。
- 场景：SaaS 宣传、科普解说、企业年报。30 fps，SVG + GSAP。
- 视觉特征：纯色大色块 / 几何角色 / 无渐变 / 干净留白 / 弹性入退场。
- seed 基因：一镜到底或色块擦除（shape wipe）转场；stagger 错峰入场、同一时刻只一个主体动；5–6 个高饱和品牌色板；squash & stretch ~10%。

### 02-line-art · 线条动画 Line Art
- 定位：单色细线一笔画，线条自我描绘（draw-on）并连续生长成整支片子。
- 场景：奢侈品、金融、建筑品牌片，logo 动画。30 fps，SVG stroke-dashoffset + 跟随笔尖的虚拟镜头。
- 视觉特征：等宽细线 / 单色或双色 / 大量负空间 / 线面转换瞬间。
- seed 基因：一条连续路径讲完整个故事（上一图形尾线 = 下一图形起线）；线宽全片恒定 2–4px；深底金线或纸底墨线；结尾线转面填充成 logo。

### 03-isometric · 等轴 2.5D Isometric
- 定位：30° 等轴测投影的微缩世界，无灭点、处处等比。
- 场景：科技公司架构图、App 功能演示、数据园区。30 fps，Three.js 正交相机或 SVG SSR 矩阵拼面。
- 视觉特征：等角投影 / 微缩场景 / 楼房生长动画 / 平行滑轨式运镜。
- seed 基因：生长式入场（底面落位 → 立面 scaleY 拉起 → 顶面延迟 2–3 帧）；运镜只整组平移不旋转，配 1:0.8:0.6 三层视差；信息密度与可爱感并存；文字可斜切进等轴平面。

### 04-3d-render · 3D 渲染系（C4D/Blender 质感）
- 定位：实体质感 CGI 动画：软胶、玻璃、金属 + 克隆阵列 + 物理感运动。
- 场景：高端产品片、品牌 ident。24 fps，Blender CLI 渲染 PNG 序列（成本重）。
- 视觉特征：PBR 真实材质 / 浅景深 / 柔和棚拍布光 / 克隆器阵列 / 糖果色软胶。
- seed 基因：无限地台 + 大面积柔光灯 + HDRI；长尾缓动（前 20% 时间走完 80% 路程）；SSS 软胶 + AO + 浅景深三件套；motion blur。

### 05-cel-boil · 逐帧手绘 / 线条沸腾 Cel Animation & Line Boil
- 定位：手绘逐帧质感，线条每隔几帧轻微抖动（boil），画面像在"呼吸"。
- 场景：手作品牌、温暖童趣内容、片头贴片。24 fps，Canvas2D 自定义笔刷渲染器。
- 视觉特征：线条持续微抖 / 一拍二一拍三 / smear 拖影帧 / 手绘烟火花水花点缀 / 纸纹底。
- seed 基因：打帧节奏（24fps 下一拍二为主，快动作切一拍一，静止一拍三）；快速位移只留 1 帧 smear（拉长 150–300%）；cel FX 点缀层；纸纹 multiply 10–15%。

### 06-collage · 拼贴剪贴 Collage / Cutout
- 定位：老照片、报纸、撕纸剪出来重新拼装的超现实风格，Monty Python 血统 + 现代杂志 finish。
- 场景：音乐类、街头潮流、文化杂志、讽刺喜剧短视频。30 fps（主体运动抽帧到 12fps），DOM/Canvas 贴图。
- 视觉特征：照片剪影白描边 / 半调网点 / 报纸纹理 / 比例失衡拼装 / 定格抽帧运动。
- seed 基因：素材抠图加 2–4px 白描边 + halftone；关节锚点 puppet 旋转、嘴巴单独两三帧开合；±2px 手摆抖动；"手把元素拍上来"或整页翻纸转场；需 CC0/公有领域图片素材。

### 07-liquid · 液态流动 Liquid Motion
- 定位：图形像液体一样流动、拉丝、滴落、融合；转场是一泼颜料漫过屏幕。
- 场景：食品饮料广告、音乐视频、转场包装、logo 揭示。30 fps，WebGL2 SDF metaball shader。
- 视觉特征：波浪边缘转场 / 拉丝与滴落 / metaball 融合 / 次级液滴跟随 / 有机曲线永不直线。
- seed 基因：缓动前快后慢（只被"甩"出去，禁匀速）；主形离开留细颈、断裂两端各回弹 2–3 帧；次级液滴延迟主体 2–3 帧跟随；结尾液体聚合成 wordmark。

### 08-morph · 形变动画 Morphing / Shape Morph
- 定位：一个图形丝滑连续变成另一个图形，图形叙事的核心语法。
- 场景：keynote 级 explainer、图标链条、概念转换。30 fps，flubber / GSAP MorphSVG。
- 视觉特征：轮廓连续过渡无跳变 / 中介形状桥接 / 形变伴随位移旋转 / 挤压拉伸。
- seed 基因：6–8 个有意义的图标按节拍连成链；复杂 A→B 先收敛为中介简形（圆/胶囊）再展开，两段各 8–12 帧；形变叠加 10–15% squash & stretch；底色随 morph 换色块；全程检查不打结。

### 09-bauhaus · 几何构成 / 包豪斯 Geometric / Bauhaus
- 定位：圆、三角、矩形在严格网格上做精确的节拍化机械运动；三原色 + 黑白限定色板。
- 场景：动态海报、音乐节、文化设计活动。30 fps，SVG/Canvas + GSAP，节拍网格（如 120 BPM）。
- 视觉特征：基础几何形 / 红黄蓝黑限定色 / 严格网格对齐 / 节拍驱动模块化运动。
- seed 基因：位移 = 网格模数整数倍、落点必在网格线上；缓动克制（easeInOutQuad 或匀速），**禁 overshoot**——机械感是特征；一拍一个动作；旋转轴心三种交替（自身中心 / 边缘顶点 / 画面中心）；结尾冻成一张完美海报。

### 10-synthwave · 复古 80s Synthwave / VHS / Y2K
- 定位：对特定年代媒介美学的整体引用：霓虹网格日落、VHS 做旧、Y2K 液态镀铬。
- 场景：音乐、游戏、怀旧营销、潮流品牌。30 fps，WebGL 网格山景 + canvas 镀铬字 + VHS pass。
- 视觉特征：霓虹辉光 / 透视网格地平线 / 扫描线与 RGB 色偏 / 镀铬金属字 / 酸性配色 / 拟物窗口 UI。
- seed 基因：synthwave 三件套（透视网格滚动 + 日落多层渐变球 + 双层辉光：内层紧 4px + 外层散 30px）；VHS 做旧链（RGB split → 扫描线 → 波浪 glitch → 4:3 遮罩可选）；镀铬字配 lens flare；关键段落抽帧到 15fps 制造磁带卡顿。

### 12-aurora-glass · 弥散渐变 / 玻璃拟态 Gradient Blur & Glassmorphism
- 定位：大色斑 aurora 光斑缓慢漂移作底，磨砂玻璃卡片浮于其上；气质是"慢、透、高级"。
- 场景：AI 产品发布、科技品牌片、高端 SaaS。30 fps，WebGL mesh-gradient shader + backdrop-filter 玻璃卡。
- 视觉特征：大色斑高斯模糊漂移 / 磨砂玻璃卡片 / 1px 高光描边 / 邻近色低对比配色 / 呼吸感慢节奏。
- seed 基因：一切慢（sine/近 linear 呼吸缓动，快动作会毁气质）；3–5 个大光斑 blur 80–150px 沿贝塞尔路径漂移；玻璃卡配方（blur 20–40px + 白 5–10% 填充 + 1px 白 30% 内描边）；配色只用邻近色 2–3 色；全局 3–5% 噪点防 banding； Liquid-Glass 透镜真折射做 wow 时刻。

### 18-hanazi · 综艺花字 Variety Show Kinetic Captions
- 定位：电视综艺后期的情绪化装饰字幕；原生 9:16 竖屏。
- 场景：vlog、萌宠、访谈、搞笑二创。30 fps 1080×1920，DOM/SVG 多层描边花字 + 底片层（CC0 图做 Ken Burns + 手持感 + punch-in）。
- 视觉特征：多层描边圆体胖体字 / 高饱和撞色+白边+投影 / 弹性 pop 入场 / 爆炸框、汗滴、闪光等手绘装饰符号。
- seed 基因：字三层结构（填充 + 粗白描边 + 彩色外描边/投影）；入场 scale 0→1.15→1.0 约 8 帧或逐字弹跳错帧 2 帧；情绪匹配（吐槽歪斜手写体、惊讶放射线爆炸框、尴尬汗滴）；花字比笑点/音效晚 2–3 帧出现；长驻留加轻微 wiggle；必须有"底片感"基础层。

### 19-paperclip · 粗描边贴纸人科普 MG（回形针/林超风格）
- 定位：回形针式知识视频包装：照片抠图加粗白边变"贴纸"，与扁平图标、精确图表铺在超宽大画布上，镜头平移缩放串联。
- 场景：硬核科普、财经知识区、企业宣传。30 fps，超宽 canvas（如 6000×3000）+ 摄像机 transform。
- 视觉特征：照片贴纸化粗白描边 / 蓝灰米白冷静底色 / 扁平图标+精确数据图表 / 大画布一镜串多信息点。
- seed 基因：一条连续摄像机路径串多个信息点（长曲线 ease）；每拍必引入一个新视觉元素；图表精确（柱状图比例、数字一致）；克制 2–3 色 + 等线字体保持严肃感；照片统一 8–12px 白描边；结尾回形针式大字标题卡（特大数字 + 小注释）。

### 20-pixel · 像素风 Pixel Art / 8-bit
- 定位：低分辨率大颗粒 + 有限色板 + 低帧率精灵动画的复古游戏美学。
- 场景：游戏内容、独立游戏宣传、怀旧营销。30 fps（精灵 8–12fps 阶梯时序），Canvas 内部低清最近邻整数放大。
- 视觉特征：大颗粒硬边像素 / 8–32 色有限色板 / 精灵帧动画 / dithering 抖动渐变 / 可选 CRT 滤镜。
- seed 基因：内部低清（如 320×180）×整数倍最近邻放大，**禁抗锯齿**；sprite 手绘帧循环（走路 6–8 帧、呼吸 2–4 帧）；steps() 阶梯时序禁平滑缓动；整像素位移；远中近三层视差卷轴；CRT 后处理不把像素糊成 mush。

### 22-hud · 赛博朋克 HUD / FUI
- 定位：科幻电影/游戏界面级的抬头显示包装，"科技感"默认皮肤。
- 场景：数码测评、游戏剪辑、军事航天科普、AI 产品演示。30 fps，SVG/Canvas FUI 层 + Three.js 线框全息。
- 视觉特征：青色/橙色霓虹线框 / 目标锁定框与准星 / 雷达环形扫描 / 等宽小字数据流 / 六边形网格与辉光。
- seed 基因：线框按层级错帧生长（stroke-dashoffset）；数字随机跳变 3–5 帧后落定、打字机文字 + 光标；锁定框四角括号 scale 1.4→1.0 快出缓入吸附；高潮处全屏翻 alert 色（青→橙红）+ "TARGET LOCKED"；全局 glow + 轻微色差 + 扫描线，glitch 克制。

## 六、选型硬规则

1. **用户点名风格** → 直接用，不再推荐。
2. **用户给了参考片/参考图** → 先从参考判断风格，再按场景校对是否最优，偏差时说明。
3. **拿不准** → 输出 1 主推 + ≤2 备选与一句话理由；用户不回复确认时按主推直接生成。
4. **15 种都不合适** → 用 `references/new-style-template.md` 为用户新造一个风格（填 Style / Output / Technical route / Creative seed / Signature features 五段）。
